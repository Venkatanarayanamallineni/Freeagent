# FreeAgent

**Your website, now taking questions.**

FreeAgent gives any business website a front desk. Paste a link, and FreeAgent reads every page and every PDF (menus, price lists, schedules), learns the brand, and gives you one line of code. Paste that line into your site and a chat bubble appears that answers customers in your voice, with a link to where each answer came from.

Built for the **NVIDIA x Nebius Global AI Hackathon** · Track: **Best Apps and Agents**

## What it does

| | |
|---|---|
| **Reads the whole site** | Crawls up to 50 pages, including PDF menus and price lists. Handles `www` redirects and detects bot-protected sites. |
| **Answers only from the site** | Short answers with a source link. If something isn't on the site, it says so and shares the business's phone or email. |
| **Talks like the team** | Says "we" and "our". Owners pick a voice: Polished, Warm or Witty. Witty mode jokes about things the business doesn't sell, without making up facts. |
| **Looks like the brand** | Pulls the logo and brand color automatically. Picks a signature icon and a subtle motion that fit what the business sells. |
| **Takes action** | Finds real booking, reservation and ordering links (OpenTable, Toast, Calendly, Vagaro, etc.) and shows a "Book now" or "Order online" button. Never invents a link. |
| **Voice** | Ask by voice and hear the answer read aloud (Chrome and Edge). |
| **Handles chains** | Asks "which location?" when hours or prices differ between locations. |

## How NVIDIA and Nebius are used

- **Model:** NVIDIA **Nemotron-3-Super-120B** (open model), served through **Nebius Token Factory** using its OpenAI-compatible API.
- **Every customer answer** is generated by Nemotron. The site's pages (sorted so price-heavy pages come first) go into the model's long context window, so no vector database is needed for small business sites.
- **At setup**, Nemotron also classifies the business (food, beauty, books, etc.) and picks the signature icon and motion for the chat bubble.
- We started with Nemotron-3-Nano-30B and switched to Super after testing: Super followed the "never invent facts" and "name the exact item" rules much more reliably.

## How it works

```
Owner pastes URL ──► crawler.py ──► pages + PDFs + logo + booking links ──► data/<site>.json
                                                         │
                                         Nemotron (style detection)
                                                         │
Customer asks ──► widget.js ──► server.py /chat ──► ask.py ──► Nemotron on Nebius ──► answer + source
```

| File | Job |
|---|---|
| `crawler.py` | Reads the site: HTML pages, PDFs, logo, name, description, booking/order links |
| `ask.py` | Builds the prompt and calls Nemotron on Nebius Token Factory |
| `server.py` | FastAPI app: `/setup`, `/chat`, `/site/{id}`, rate limits, input checks |
| `static/setup.html` | Landing page and setup flow (receipt, install card) |
| `static/widget.js` | The chat bubble businesses embed on their site |
| `static/preview.html` | Preview page used in the install card |
| `demo_data/` | Saved demo sites so the live demo survives server restarts |

## Run it locally

You need **Python 3.10+** and a **Nebius Token Factory API key**.

```bash
git clone <this repo>
cd freeagent
python -m venv venv

# Windows
venv\Scripts\activate
# Mac / Linux
source venv/bin/activate

pip install -r requirements.txt
```

Copy `.env.example` to `.env` and fill in your values:

```
NEBIUS_API_KEY=your_key_here
NEBIUS_BASE_URL=your_base_url_here
MODEL_ID=your_model_id_here
```

In Token Factory, open the Nemotron model, click **View code**, choose **Python**, and copy the `base_url` and `model` values.

Start the server:

```bash
uvicorn server:app --reload
```

Open **http://127.0.0.1:8000**, paste a business website link, and click **Hire my assistant**.

### Command-line tools (optional)

```bash
python crawler.py https://example.com        # crawl a site into data/
python ask.py data/example_com.json          # chat with it in the terminal
```

## Deploy (Render)

1. New **Web Service** from this repo.
2. Build command: `pip install -r requirements.txt`
3. Start command: `uvicorn server:app --host 0.0.0.0 --port $PORT`
4. Add the three environment variables from `.env`.

Render's free tier wipes its disk on restart, so sites set up there disappear. Sites saved in `demo_data/` always survive.

## Safety and limits

- **Rate limits:** 15 chats per minute per visitor, 10 setups per hour, and a daily cap across all visitors, to protect API credits.
- **Input checks:** site IDs are validated, chat history only accepts normal user and assistant turns, and the crawler refuses private or internal network addresses.
- **API key** stays on the server in environment variables. It is never sent to the browser or committed.
- **Known limits:** sites that build their content with JavaScript, or that block bots (for example Cloudflare's "Just a moment" page), can't be read. Menus that are scanned images inside PDFs can't be read yet. Voice input depends on the browser's own speech service.
